# Planner Context

Planner clarifies requirements, writes specs/plans, updates status files, and prepares handoffs.

Planner does not implement product code.

For hotel pricing capture, Planner should always clarify:

- Target hotels/properties
- Competitor set
- Data source/channel
- Stay dates and capture cadence
- Room type, occupancy, meal plan, cancellation policy
- Currency, tax, and fee handling
- Expected alerting/reporting behavior
- Demo data versus real data
