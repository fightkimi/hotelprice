# 投资人演示原型

这是酒店竞品价格雷达的本地静态演示应用，用于销售沟通、需求访谈和投资人初筛。所有价格、酒店、房型、平台、事件趋势和提醒信息均为演示数据，不连接真实 OTA 系统，也不会直接修改酒店价格。

## 打开方式

直接用浏览器打开：

```text
prototypes/client-demo/index.html
```

不需要安装依赖，不需要后端服务。

## 客户讲解顺序

1. 今日市场概览：先看今日需要关注的市场变化、提醒数量和本酒店价格风险。
2. 未来 30 天价格日历：选择一个入住日期，查看核心竞品均价、价格范围和提醒原因。
3. 核心竞品监控：切换全部、核心竞品、市场参考，查看各酒店的最低价和监测状态。
4. 异常提醒中心：按涨价、降价、市场均价、低价风险筛选提醒，并查看需人工复核的依据。
5. 设置流程预览：展示客户如何确认本酒店、竞品、渠道和监测范围。

## 投资人演示顺序

1. 看首页能力条：房型覆盖、平台覆盖、事件趋势、平台价差，说明产品不只是单一价格提醒。
2. 切换房型：在标准大床房、标准双床房、亲子房、套房之间切换，观察 KPI、趋势线、日历和提醒联动。
3. 切换平台：在携程、美团、飞猪、同程演示源之间切换，观察平台价差条形图和样本覆盖说明。
4. 查看市场趋势线：说明本酒店价、核心竞品均价和事件影响如何同时呈现。
5. 点击端午、会展、演唱会演示日期：查看热力日历、房型拆分和平台价差。
6. 打开异常提醒：展示房型价差、平台价差、节假日趋势提醒，并强调所有建议需人工复核。

## 演示边界

- 数据口径：样例数据，人民币 CNY，默认含税费估算，按房型标准化。
- 房型口径：标准大床房、标准双床房、亲子房、套房均为演示房型。
- 平台口径：携程、美团、飞猪、同程均为演示源，不代表真实市场准确性。
- 事件口径：端午演示假期、会展演示日、演唱会演示日均为样例事件趋势。
- 来源口径：固定演示日期为 2026-05-18。
- 决策口径：界面只提示建议关注和需人工复核，不给出强制价格动作。
- 系统口径：静态 HTML/CSS/JavaScript，本地打开即可查看。
