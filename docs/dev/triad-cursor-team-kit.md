# Triad + Cursor Team Kit

Use these skills when available:

- `new-branch-and-pr`: create or confirm a feature branch and prepare PR workflow.
- `check-compiler-errors`: run type/build/compiler checks.
- `control-ui`: browser-based UI checks when a front end exists.
- `verify-this`: verify a specific claim.
- `run-smoke-tests`: run existing smoke tests.
- `deslop`: remove unnecessary AI-generated complexity before PR.
- `make-pr-easy-to-review`: prepare clear PR notes.
- `review-and-ship`: final review before PR handoff.
- `loop-on-ci`, `fix-ci`, `get-pr-comments`: handle CI and PR feedback.

These do not replace Superpowers. Superpowers is the mandatory stage workflow; Cursor Team Kit helps with PR, CI, UI, and review mechanics.
